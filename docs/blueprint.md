# **App Name**: Peñamellera Deportes

## Core Features:

- Homepage: Displays featured sports and a brief introduction to the Peñamellera sports scene with SEO-optimized copy.
- Sport Overview: Provides dedicated sections for key sports (Ajedrez, Bolo Palma, Montaña), each optimized with sport-specific content and SEO keywords.
- Event Calendar: Presents an interactive calendar with information of upcoming tournaments, matches, and races. Allow for filtering events per sport.
- Contact Form: Enables users (clubs, organizations, individuals) to submit their sports activities for inclusion on the portfolio. The submission may include title, description, sport type, event date and link.

## Style Guidelines:

- Primary color: A vibrant green (#74B72E), reflecting the lush landscapes of Peñamellera.
- Background color: A light, desaturated green (#E8F5E0) for a clean and natural feel.
- Accent color: A complementary orange (#FFB347) to highlight important CTAs and interactive elements.
- Headline font: 'Poppins', sans-serif, for titles and headings.
- Body font: 'PT Sans', sans-serif, for the body of the articles.
- Use icons to represent each sport (chess, mountain running, traditional bowls) and to add visual cues throughout the calendar.
- Homepage section layout will consist of 3 columns showing a picture and the sport in question (Chess, Soccer, 'Deporte') based on the image. Further pages include three articles at a time (Ultimos articulos).
